## 1. Search Intent Architecture

Zoqonyx tool pages do not merely target generic tool labels (such as "Image Converter"). Instead, every tool is mapped to the authentic, multi-layered queries users enter into search engines when faced with specific technical hurdles:

1. **Primary Keywords (High Commercial / Task Intent):** The direct solution query (e.g. `convert PNG to WebP online`, `generate schema markup`).
2. **Secondary & Synonym Keywords:** Alternative technical terminologies (e.g. `JSON-LD generator`, `WebP photo encoder`, `CSS glassmorphism alternative`).
3. **Long-Tail Search Queries:** Specific technical variants (e.g. `compress 50MB JPG to under 200KB`, `format unformatted JSON with 2 space indent`).
4. **Problem-Based Search Queries:** The user's underlying issue or error (e.g. `how to speed up Google PageSpeed LCP score`, `how to sign PDF without Adobe Acrobat subscription`).
