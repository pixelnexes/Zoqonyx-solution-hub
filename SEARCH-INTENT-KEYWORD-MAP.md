## 1. Overview & Strategy

Users searching for utility tools do not query generic technical taxonomies (e.g., "Image Processing Utility"). They search with concrete task-oriented queries (e.g., "convert png to webp online", "compress jpg to 100kb", "merge pdf without watermark").

This map documents the core keyword clusters, user search intent, query variations, and on-page integration patterns across Zoqonyx's tool catalog.

## 3. Comprehensive Category Search Intent Framework

| Category | Primary Search Intention | Common User Problem | On-Page Solution Pattern |

| **Image Tools** | Immediate format transcoding, dimension scaling, or byte compression. | File too large for web upload; unsupported image extension. | Clean dropzone, 1-click format presets, live split preview, instant ZIP download. |

| **Text & Code** | Cleaning messy text, transforming cases, generating test data or slugs. | Inconsistent capitalization, duplicate lines, trailing whitespace, character limits. | Instant keystroke transformations, word/character metrics, clean exports. |
| **Calculators** | Quantitative computation of financial, chronological, health, or unit values. | Complicated formulas prone to manual arithmetic or rounding errors. | Real-time reactive calculation as user types, formula breakdowns, privacy assurance. |
